# E-voting-system-using-blockchain
======================================================================
A decentralized, decentralized ledger-driven electronic voting framework engineered to eliminate voter fraud, prevent ballot tampering, and optimize electoral costs. This system bridges the gap between digital accessibility and national-security-grade electoral integrity by combining Blockchain technology, Hybrid Cryptography, and Computer Vision.

🌟 Key Core Pillars
Immutability via Blockchain: Utilizes a distributed ledger structure and automated smart contracts to record cast votes. This guarantees that once a vote is submitted, it can neither be altered, duplicated, nor deleted by any internal or external entity.

Dual-Layered Cryptographic Infrastructure:

AES (Rijndael) Algorithm: Symmetric 128/256-bit encryption protects sensitive voter profiles, identification records, and database storage.

RSA Cryptosystem: Public-key asymmetric encryption guarantees secure, intercepted-proof data transmission lines between the voter client and backend infrastructure.

Biometric Authentication via OpenCV: Integrates a real-time computer vision layer to run facial recognition and biometric checks before unlocking the ballot, preventing identity theft and credential sharing at the point of voting.

👥 System Governance & Roles
Voter Portal: Enables secure biometric login, digital voter ID application, candidate registry browsing, secure encrypted ballot casting, and immediate automated ballot validation checks.

Election Commission Dashboard: Acts as the central oversight authority responsible for verifying credentials, approving voter/candidate registration requests, and monitoring real-time consolidated voter Turnout metadata.

Candidate Portal: Streamlines official political nominations, unique logo allocation, and official web-portal election result viewing.

🔮 Future Engineering Roadmap
Transitioning from pilot simulation environments to fully production-grade distributed databases.

Optimizing messaging and packet data sizing to maximize protocol bandwidth over high-traffic regional networks.

Evaluating homomorphic encryption modules to allow ballot counting without decrypting individual voter choices, amplifying privacy.

Building a reliable online voting structure that delivers the absolute fairness of traditional physical ballots while achieving the scale and efficiency of modern software systems has been a monumental challenge in tech for years.

To tackle this, I developed a decentralized e-voting architecture designed to eliminate duplicate voting, prevent identity theft, and bring absolute transparency to modern electoral processes.

🛠️ How It Works:
Biometric Guardrails (OpenCV): Voters pass through a real-time face authentication pipeline to verify their identity before gaining access to the digital ballot box.

Hybrid Cryptography (AES & RSA): High-security voter profiles are kept encrypted at rest using symmetric AES, while asymmetric RSA handles secure data transmission lines to prevent man-in-the-middle attacks.

Tamper-Proof Ledger (Blockchain): Cast votes are committed immutably to a distributed ledger via smart contracts. This completely blocks double-voting and renders the final count 100% tamper-proof.

👥 The Architecture Integrates Three Distinct Portals:
Voters: Biometric authentication, secure casting, and validation.

Election Commission: Secure verification, cataloging, and transparent tracking.

Candidates: Direct dashboard overview for nomination filings and live results.

This project highlights exactly how security, decentralized governance, and clean UX can converge to create a transparent, efficient, and trustworthy digital marketplace for public choice.
